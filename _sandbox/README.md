## Script Sandbox

The scripts in this folder are equivalent to 'back of the envelope' sketches; they may not adhere to reproducibility best practice or otherwise be obviously written for a single user to run their code so _run code in this folder that you did not write at your own risk!_

Scripts that prove worthwhile to formal products/workflows from this group will be renamed and moved out of this folder--at which point, they will be refactored to meet the minimum FAIR standards used in other 'actual' scripts.
